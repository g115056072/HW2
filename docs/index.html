CRISP-DM Procedure

  1. Business Understanding: define objective, target, and success metrics (MAE, RMSE, $R^2$).
  2. Data Understanding: inspect schema, missing values, target distribution, and relationships.
  3. Data Preparation: handle invalid rows, engineer date features, avoid leakage, split train/test before selection.
  4. Modeling: simple linear baseline, multiple linear with one-hot + top-k selection, and autoregression on daily medians.
  5. Evaluation: compare held-out results; AR is evaluated chronologically on future periods.
  6. Deployment: monitor quality, drift, and retraining cadence in production.
